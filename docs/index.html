01 / Capabilities

Built for rigorous research

ARGUS is a research planner and verifier. You — or your AI agent — do the reading. ARGUS makes sure nothing ships unverified.

PLN-01

Research planner

A vague question becomes a structured 5-wave plan: sub-questions, modes, consent gates. Broad → regional → technical → discussion → verify.

VRF-02

Verify gate

Audits the finished report: structure, live links, citation coverage, language breadth. Nothing ships with dead links.

LNG-03

14 languages

Cross-language evidence by default — Arabic, Chinese, Spanish, Russian, Hindi and more. Not Google-only English answers.

DEP-04

Zero dependencies

Pure Python stdlib. No supply-chain risk, auditable line by line, runs even in air-gapped environments.

TG-05

Telegram preview

Safe channel previews with strict URL validation and pinned hosts. Scraping and forums stay behind explicit consent gates — silence always means SKIP.

AGT-06

Agent-native

MCP server for AI assistants, plus a loopback-only local bridge with Chrome and VS Code companions for field work.

02 / Operating modes

Seven modes, one CLI

From a 100-word verified answer to a 5,000-word deep investigation. Pick the depth the question deserves. Plus argus-lite — an institutional preset with silent gates.

ModeUse when
quickThe question has one verified answer — one authoritative source, cited.
compareA vs B decision — definitions, ownership, pricing, side by side.
deepThe full investigation — scope, timeline, key players, evidence. Up to 5,000 words.
platformWhat exists about the topic on one platform — content, formats, voices.
timeboxedA dated timeline spine of key events inside your window — each one cited.
regionalRegion-first research — which countries, why these, what is excluded.
narrowLaser scope — a precise definition plus verified facts only. No fluff.
03 / Protocol

How it works

Three steps. No API keys, no accounts, no cloud.

STEP 1

You ask

One vague question in. argus plan "EV battery supply chains" --mode deep returns sub-questions, waves, consent gates.

STEP 2

You research

Follow the plan — yourself, or with your AI agent via the MCP server. ARGUS generates the report skeleton; you fill in findings.

STEP 3

ARGUS audits

argus verify report.md --live-links checks structure, every link, citations and language coverage before anything ships.

05 / Deployment

Install in 30 seconds

Python 3.9+ · macOS, Linux, WSL · Apache-2.0

$ pipx install emo-argus
$ argus plan "your question" --mode deep
$ argus verify report.md --live-links
Why pipx? Isolated install — never touches system Python. You get argus, argus-lite, argus-mcp and argus-bridge on PATH. Upgrade any time: pipx upgrade emo-argus.
06 / Threat model

Security is a feature

Designed for researchers handling sensitive topics — hardened by default, not by configuration.

  • ✓

    Loopback-only bridge. Binds 127.0.0.1 with a per-boot HMAC token. No LAN exposure, no DNS rebinding.

  • ✓

    Path traversal guards. Every file write is jailed to the working directory; MCP tools can't escape it.

  • ✓

    Consent gates. Scraping and forums require explicit approval. Silence always means SKIP.

  • ✓

    Zero dependencies. Pure stdlib core means no supply-chain attack surface to audit.
