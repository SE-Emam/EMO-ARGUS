Built for rigorous research

ARGUS is a research planner and verifier. You (or your AI agent) do the reading — ARGUS makes sure nothing ships unverified.

🗺️

Research planner

A vague question becomes a structured 5-wave plan: sub-questions, modes, and consent gates — broad → regional → technical → discussion → verify.

🛡️

Verify gate

Audits the finished report: structure, live links, citation coverage, and language breadth. Nothing ships with dead links.

🌍

14 languages

Cross-language evidence by default — Arabic, Chinese, Spanish, Russian, Hindi and more, not Google-only English answers.

📦

Zero dependencies

Pure Python stdlib. No supply-chain risk, auditable line by line, runs even in air-gapped environments.

📡

Telegram preview

Safe channel previews with strict URL validation and pinned hosts. Scraping and forums stay behind explicit consent gates — silence always means SKIP.

🤖

Agent-native

MCP server for AI assistants, plus a loopback-only local bridge with Chrome and VS Code companions for field work.

Seven modes, one CLI

From a 100-word verified answer to a 5,000-word deep investigation — pick the depth the question deserves.

quick

The single verified answer — one authoritative source, cited. For questions with one right answer.

compare

A vs B, side by side — definitions, ownership, pricing models. For decisions.

deep

The full investigation — scope, timeline, key players, evidence. Up to 5,000 words.

platform

What exists about the topic on one platform — content, formats, voices.

timeboxed

A dated timeline spine of key events inside your window — each one cited.

regional

Region-first research — which countries, why these, what is excluded.

narrow

Laser scope — a precise definition plus verified facts only. No fluff.

Plus argus-lite — an institutional preset with silent gates for fast team use.

How it works

Three steps. No API keys, no accounts, no cloud.

You ask

One vague question in. argus plan "EV battery supply chains" --mode deep → sub-questions, waves, consent gates.

You research

Follow the plan — yourself or with your AI agent via the MCP server. ARGUS generates the report skeleton; you fill in findings.

ARGUS audits

argus verify report.md --live-links checks structure, every link, citations, and language coverage before anything ships.

Install in 30 seconds

Python 3.9+ · macOS, Linux, WSL · Apache-2.0

$ pipx install emo-argus
$ argus plan "your question" --mode deep
$ argus verify report.md --live-links

Why pipx?

  • Isolated install — never touches your system Python
  • argus, argus-lite, argus-mcp and argus-bridge on your PATH
  • Upgrade any time: pipx upgrade emo-argus

Security is a feature

Designed for researchers who handle sensitive topics — hardened by default, not by configuration.

✓

Loopback-only bridge. The local bridge binds 127.0.0.1 with a per-boot HMAC token — no LAN exposure, no DNS rebinding.

✓

Path traversal guards. Every file write is jailed to the working directory; MCP tools can't escape it.

✓

Consent gates. Scraping and forums require explicit approval. Silence always means SKIP.

✓

Zero dependencies. Pure stdlib core means no supply-chain attack surface to audit.
